# PBRT 材质

## 资产与 GPU 准备

`PbrtMaterial` 沿用 MaterialAsset 的 ID 与多态存储，按模型保存反射、透射、折射率、各向异性粗糙度、涂层、次表面、毛发和混合材质参数，以及实测 BRDF、法线图与位移引用。浮点输入区分常量和纹理；光谱保存原始类型、色彩空间和数据。导入时解析引用并落实固定版本的默认参数。

OfflineScene 将材质准备为散射模型头或颜色求值程序，纹理输入编译为后缀指令。独立的光滑 dielectric 和 conductor 直接引用散射参数对应的纹理程序；颜色近似及混合颜色按子节点在前的顺序求值。纹理和混合颜色各使用 64 项值栈，类型与容量由 CPU 和 shader 共享定义。

材质和纹理在内容变化时重新准备与上传，图像和采样器复用全局资源表，目前容量分别为 128 和 32。实现位于 [OfflineScene.cpp](../../src/render/raytracing/offline/OfflineScene.cpp)、[material.slang](../../shaders/raytracing/offline/material.slang) 和 [brdf.slang](../../shaders/raytracing/offline/brdf.slang)。

## 已接入的散射模型

| 材质 | 处理方式 |
| --- | --- |
| diffuse | 反照率限制在 [0, 1]，使用 Lambert BRDF 与余弦半球采样，路径吞吐量乘以反照率 |
| 光滑 dielectric | 依据折射率和 Fresnel 概率选择镜面反射或折射，处理内外侧折射率、全反射及辐亮度传输缩放 |
| conductor | 复折射率 Fresnel、各向异性 GGX、Smith 遮蔽与可见微表面法线采样；接近零粗糙度时使用镜面反射 |

几何法线决定射线偏移和反射半球，着色法线决定散射求值与采样。各向异性使用网格切线框架，并随实例的完整仿射变换进入世界空间。

## Conductor

支持 `eta / k` 与 reflectance 两种光学输入，以及独立的 U/V 粗糙度；这些输入均可引用纹理。reflectance 输入按 PBRT 的方式转换为 `eta = 1` 和对应的 `k`，再使用导体 Fresnel 求值随角度变化的反射率。

`remaproughness` 开启时，以粗糙度的平方根作为 GGX 的 α；关闭时直接使用输入值。粗糙表面按 GGX 可见法线分布采样，反射到表面下方的样本贡献为零；接近光滑时按镜面反射处理。

模型依据 [PBRT 导体 BRDF](https://pbr-book.org/4ed/Reflection_Models/Conductor_BRDF)。当前 `veach_bidir` 中的 `Lamp` 使用 RGB `eta / k`、U/V 粗糙度 0.25，并关闭粗糙度重映射。

## 与光源采样的衔接

Diffuse 和粗糙 conductor 都参与直接光采样，面积光的 NEE 与 BRDF 采样使用各自一致的 PDF 做 MIS。光滑玻璃和镜面导体通过镜面路径取光，命中发光面时权重为 1。发光几何体继续使用自身材质散射，因此一个表面可以同时发光和反射。

光源分组、蓄水池、可见性查询及面积光 PDF 见 [光源](光源.md)。

[BDPT](BDPT.md) 复用这些散射模型，在命中时缓存材质求值结果，并分别计算相机侧 Radiance 与光源侧 Importance 传输。玻璃透射的折射率平方修正只用于 Radiance，光源侧按伴随传输处理着色法线。

## 光谱与颜色近似

| 输入或模型 | 当前处理 |
| --- | --- |
| RGB 光谱 | 直接使用 RGB 数值，原始色彩空间保存在资产中 |
| 采样光谱、黑体 | 在 610、550、460 nm 取样或计算相对值 |
| 命名光谱、外部光谱文件 | 中性白色占位，完整来源保存在资产中 |
| coatedconductor、混合程序中的金属 | 使用反射颜色近似，表面按 diffuse 散射 |
| 粗糙 dielectric、thin dielectric | 使用中性颜色近似，表面按 diffuse 散射 |
| coateddiffuse、diffusetransmission、次表面、毛发 | 从已保存参数生成颜色近似，表面按 diffuse 散射 |
| 实测 BRDF、具名散射 | 中性表面颜色占位 |

涂层、多模型混合散射、精确光谱求值、介质、alpha 和法线图的渲染接入留待后续实现。纹理转换、过滤与 Ptex 的处理见 [资产转换](../PbrtConversion.md)。
