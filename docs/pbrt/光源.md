# PBRT 离线光源

## 数据流程

导入阶段将 PBRT 光源转换为场景组件：解析光源使用 LightComponent 的具体类型，环境光使用 EnvironmentLightComponent，发光几何体使用绑定 RenderComponent 子网格的 MeshAreaLightComponent。组件保存原始发光光谱、scale、图像、power / illuminance 和介质引用。

RenderSystem 收集启用的组件，生成 OfflineLightData。OfflineScene 按类型准备独立的 GPU 数组，图像和采样器复用 MaterialTable 的全局资源表。离线 shader 通过 `light.slang` 访问光源。

| PBRT 类型 | GPU 类型 | 传入内容 |
| --- | --- | --- |
| point | OfflinePointLight | 世界空间位置、自身发光参数 |
| spot | OfflineSpotLight | 世界空间位置和方向、内外锥角余弦、自身发光参数 |
| distant | OfflineDirectionalLight | 世界空间方向、自身发光参数 |
| diffuse 面积光 | OfflineLightTriangle | 世界空间三角形、面积、法线、UV、单双面标记、发光网格的共享参数索引 |
| infinite | OfflineEnvironmentLight | 世界到环境图局部坐标的变换、portal 范围、自身发光参数 |
| projection | OfflineProjectionLight | 世界空间位置、世界到投影坐标的变换、FOV、自身发光参数 |
| goniometric | OfflineGoniometricLight | 世界空间位置、世界到方向图局部坐标的变换、自身发光参数 |

RenderSystem 从场景变换中提取位置和方向。point 记录直接保存位置和自身发光参数，共 64 B；spot 和 distant 的方向由本地 -Z 轴变换并归一化得到。环境光、projection 和 goniometric 分别保存自身图像映射所需的 lightFromWorld。环境光和 goniometric 图像沿用导入阶段保留的 PBRT 本地坐标。

## 发光几何体拆分

当前将每个发光子网格按索引顺序展开为多个三角形面积光源。例如 veach_bidir 的两个发光四边形各生成两条记录，共四条三角形光源。

三角形顶点经过 DrawItem.model 的完整仿射变换，保存世界空间位置、世界空间面积、几何法线和三个顶点的 UV。法线处理 ReverseOrientation 和镜像变换，供单面发光判断使用；双面发光由光源标记控制。零面积三角形保留编号，发光求值返回零。

每个 DrawItem 保存三角形表的起始索引，shader 使用“起始索引 + PrimitiveIndex”找到当前命中的光源。每片三角形记录为 96 B，同一发光子网格的三角形共享一份发光参数。各实例分别生成光源记录，几何资产和 BLAS 继续共享，TLAS 保持每帧构建。

发光信息属于光源组件，反射属性属于材质。三角形拆分仅发生在 GPU 光源数据准备阶段，场景资产仍保存原来的网格和面积光组件。

## GPU 资源

离线 Pass 的 Set 3 按下表绑定：

| Binding | 资源 |
| --- | --- |
| 0 | TLAS |
| 1 | 命中对象表 |
| 2 | 材质指令 |
| 3 | 纹理指令 |
| 4 | 发光网格共享参数表 areaEmissions |
| 5 | point 数组 |
| 6 | spot 数组 |
| 7 | distant 数组 |
| 8 | 面积光三角形数组 |
| 9 | infinite 数组 |
| 10 | projection 数组 |
| 11 | goniometric 数组 |
| 12 | 环境光 portal 世界空间顶点 |
| 13 | 渐进累积缓冲 |
| 14 | 输出图像 |

push constants 分别提供七类光源的数量及 portal 顶点数。shader 按类型访问对应数组，背景求值只遍历环境光数组。空表分配一个占位元素，实际元素数为零。

发光参数保存 I / L 的 RGB 预览值、scale、可选 power / illuminance、图像引用和介质索引。point、spot、distant、infinite、projection 和 goniometric 直接在自身记录中保存这些值。只有发光网格将 48 B 的参数存入 areaEmissions，由拆出的三角形通过 emissionIndex 共享。介质索引对应 OfflineSceneData.lightMedia 中的资产 ID，介质的传播参数留待体积渲染接入。

面积光的共享发光参数保存原发光子网格的总功率和世界空间总面积。后续按原发光子网格统一归一化，保证拆分前后的总功率一致。

场景、光源参数或资产内容变化时重新准备并上传数据，同时重置渐进累积。数据保持不变时复用现有缓冲内容；缓冲重新分配时更新对应绑定。光源图像与材质图像共用全局纹理和采样器容量。

## 离线路径追踪

反弹次数由独立配置 `feature.offline.maxBounces` 控制，默认 2，表示最多两次表面散射。每个像素每帧生成一条始终抖动的相机路径，通过循环逐次追踪，并做渐进算术平均。相机直接命中的面积光保留完整发光值；末次散射之后继续保留命中的发光面或环境。发光面同时具有 diffuse 反射属性。

当前所有表面使用 Lambert diffuse BRDF：材质颜色与纹理求值结果限制在 [0, 1]，作为反照率，BRDF 为 albedo / π。BRDF 按余弦半球分布采样，路径吞吐量每次乘以 albedo。几何法线用于射线偏移及半球判断，着色法线用于 diffuse 求值和采样。改变反弹次数时清空累积。

### 三个独立蓄水池

每个可散射的表面分别执行以下三组光源采样，每组最多保留一个候选，并只对最终选中的候选发出阴影射线：

| 分组 | 选择权重与处理 |
| --- | --- |
| point + spot | 共用一个蓄水池，权重为到达表面的 RGB 强度最大通道，包含距离平方反比和 spot 锥角衰减 |
| distant | 独立蓄水池，权重为 RGB 最大通道；方向指向光源，阴影射线延伸至无限远 |
| area | 所有三角形面积光共用一个蓄水池，权重由世界空间面积、三角形中心到着色点的距离平方反比、发光面朝向和发光强度估计组成 |

point / spot 使用原始强度 I，沿距离平方衰减。spot 在内锥内保持完整强度，在外锥外衰减到零；过渡区使用余弦归一化值的四次方。内外锥重合时使用硬边界。distant 保持距离无关的光照。三组都通过“所选权重 / 权重总和”得到选择概率，并在贡献中除以该概率。离线解析光源覆盖全场景，作用范围由距离及锥角决定。

area 使用均匀三角形面积采样，UV 由重心坐标插值。带图像的光源采用 scale 作为选择权重中的强度估计，让图像中各处的发光都保有采样支持；实际贡献在采样位置读取图像。单双面标记同时参与选择权重、发光求值与 PDF 计算。

### 面积光与 BRDF 的 MIS

面积光采样的完整立体角 PDF 为：三角形选择概率 × 距离平方 /（三角形面积 × 发光面余弦）。它与 diffuse BRDF 的 cos / π PDF 使用 balance heuristic 合并，权重为自身 PDF / 两者 PDF 之和。

BRDF 射线命中发光三角形时，根据上一表面的面积光权重总和，重建当前三角形的选择概率与完整光源 PDF，使用另一侧的 MIS 权重计入发光。两种采样使用同一个偏移后射线原点及同一套三角形选择权重。point、spot 和 distant 按 delta 光源单独计入直接光。

环境光由相机或 BRDF 射线未命中时求值，多盏环境光相加，图像使用 PBRT-v4 等面积映射。projection 和 goniometric 的数据继续上传，光照求值留待后续接入。

路径和阴影查询均从 raygen 发出，closest-hit 仅返回交点数据。阴影查询使用独立的 miss 记录、首命中结束和跳过 closest-hit，光追 Pipeline 递归深度保持 1。离线 BRDF、蓄水池、三角形采样与 MIS 实现在 `shaders/raytracing/offline`，通用基础设施复用随机数、Sobol、纹理和相机数据。

## 当前数值近似

光源光谱复用现有 RGB 转换：RGB 直接取值，采样光谱和黑体使用三个波长近似，命名光谱与外部光谱文件使用白色占位。原始光谱和色彩空间继续保存在资产中。发光图像替代 L 后应用 scale，面积光图像按 PBRT 表面 UV 翻转 V，环境图按等面积映射直接读取。

power / illuminance 已上传，当前光照应用 RGB 与 scale，光度归一化、完整 PBRT 材质散射、介质、alpha 和法线图是后续工作。
