建议按这个顺序，每一步都保留传统路径作为对照：
1. 完善命中信息和材质
   接入 metallic、roughness、normal、emissive；区分几何法线和着色法线，处理双面与 alpha mask，改进射线起点偏移。
2. 完整 BRDF 采样
   从 Lambert 扩展到漫反射 + GGX 镜面，统一 evaluate / sample / pdf，正确处理混合采样概率。Clearcoat 暂时放后面。
3. 完善传统直接光采样
   支持方向光、环境光重要性采样和自发光网格；多光源从“逐灯采样”改为“按概率选灯”，把选灯概率计入 PDF。
4. 完善路径追踪积分器
   显式记录 throughput、上一跳 PDF 和事件类型；统一 NEE、命中发光体的 MIS；增加俄罗斯轮盘终止。建议逐步改为 raygen 循环追踪，分离反弹次数和 Vulkan 递归深度。PBRT
5. 采样与静态累积
   加入帧索引、像素内抖动、每帧 SPP；HDR 历史累积；相机、场景、材质或灯光变化时重置。先得到能收敛的参考画面。
6. 实时重投影基础
   输出深度、法线、albedo、motion vector；保存历史数据，检测遮挡变化并拒绝无效历史。
7. 传统实时降噪
   分离直接光和间接光，逐步实现时间累积、方差估计、边缘保持的 à-trous 滤波，组成简单 SVGF。SVGF 论文
8. 整理性能与调试
   避免无变化时重建加速结构；增加各阶段 GPU 耗时、采样/PDF/历史有效性调试视图，保留高 SPP 参考模式。
9. 最后接 ReSTIR DI
   按“候选生成 → 单像素 RIS → 时间复用 → 空间复用 → 可见性与最终估计”推进，与传统 NEE 对比。稳定后再考虑 ReSTIR GI/PT。RTXDI 集成说明
眼下优先做 1～4，先保证积分和材质正确，再处理实时噪声。
